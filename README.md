# Khushaal Arora — Vampire Noir Portfolio

A multi-page personal portfolio built with semantic HTML5 and one shared CSS stylesheet. No JavaScript or frameworks.

## Preview
Open `index.html` in a browser. All pages use relative links and local assets.

## Pages
- `index.html` — Home
- `about.html` — About
- `experience.html` — Experience
- `geekskii.html` — GEEKSKII RECORDS
- `collaborations.html` — Fashion collaborations
- `projects.html` — Music-video, visual and tattoo practice
- `education.html` — Education and learning interests
- `contact.html` — Contact

## Files
- `style.css` — shared responsive styling
- `assets/` — supplied portfolio photography and artwork

## Design
Obsidian black, blood-crimson accents and white typography; editorial serif, condensed display, sans-serif and mono type pairing; Japanese labels; subtle grain, hover states, marquee and responsive layouts.

Fonts are loaded from Google Fonts when online. Local fallback fonts are defined for offline preview. Monument Extended is referenced first when installed locally; Anton is the fallback display face.

## Hosting
Upload the contents of this folder to the root of a GitHub repository and enable GitHub Pages from `main` / root.


Visual revision: the supplied monochrome action photograph is used as a heavily darkened, fixed site-wide background. The palette is OLED black, white text and deep blood crimson. The pointer uses a custom SVG blood-drop cursor, with a brighter/larger drop state over links. Large Japanese display typography is used in the hero and page headers.
